# shared/data-modules

Reusable **pipeline / warehouse templates** each venture's
[`data-platform/`](../../ventures/) builds on — e.g. an ingestion pattern, a
dbt-style model scaffold, CDC/streaming boilerplate, a standard analytics event
schema. **Placeholder.**

Goal: a new venture gets a working, conventions-following data pipeline by
composing these rather than starting from scratch. Distinct from venture
`data-platform/` folders, which hold each venture's *actual* pipelines.
