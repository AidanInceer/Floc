# @shared/design-system

Design **tokens and theming primitives** — colours, spacing, typography, radii,
shadows, light/dark theming — the single source of visual truth. **Placeholder.**

`ui-kit` and every venture's `apps/*` consume these tokens; nothing here depends
on React component internals. Distinct from `ui-kit`: this is *values and
theming*, `ui-kit` is *components*.
