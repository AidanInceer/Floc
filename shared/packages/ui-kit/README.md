# @shared/ui-kit

Reusable **React component library** built on `@shared/design-system` tokens —
buttons, cards, forms, tables, charts, layout primitives. **Placeholder.**

Consumed by every venture's `apps/*`. Accessible and themeable by default. Keep
components venture-agnostic — no product-specific logic. Component-level design
guidance can be seeded from the finance-planner mockups in
[`../../../ventures/finance-planner/docs/mockups/`](../../../ventures/finance-planner/docs/mockups/).
