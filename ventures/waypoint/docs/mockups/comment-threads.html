The run is the unit. One top-level comment plus everything hanging off it, separated from the next run by a dotted rule. The solid rule down the left of the replies is what makes them read as attached rather than as top-level comments that happen to be indented.

Replying to a reply stays in the run. Aidan answered Sam, not Ruth — so his comment names Sam in the pen colour and sits at the same indent. That is the whole cost of one level, paid in three words, and it buys a thread that never runs out of horizontal room inside a 512px modal.

One indent, 35px + a 14px gutter. At 375px that leaves a reply about 44 characters a line, which still reads. A second level would not.

Reply composers open on demand, one at a time — the ticket's "a lot of textareas on a busy page" complaint. Only the thread's own composer, at the bottom, is always open, and it is fenced off by a solid rule so it doesn't read as a reply to the last run.

Timestamps got finer. Relative for the last day ("2h ago", "Yesterday"), then day-and-time ("Tue 14:20"). Two comments an hour apart no longer carry the same stamp.

Delete only shows on your own (or on anything, if you're an admin), and it stays a word rather than a ×. Editing is still absent — deliberately: rule 7 is last-write-wins, and an edited argument that people have already replied to is a rewritten one.
