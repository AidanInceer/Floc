CI

Three workflows in .github/workflows/. CI proves the code builds, passes and keeps its schema true. It does not deploy. Railway deploys on push to main; phone builds go by hand.

Paused: changes, mobile, mobile-android, e2e-web and wireframes are skipped with if: false to keep the Actions bill down. Grey in the diagram. pnpm verify still runs e2e, wireframes and the bundle locally. To restore, delete the if: false line.

Jobs

JobDoesFails on
verifyLint, typecheck, test, build, fitness (layers, dead code, tokens, contrast, bundle). Only affected packages.Any step
changes · pausedAsks git if apps/mobile/, packages/ or the lockfile moved.—
mobile · pausedMetro bundles both platforms. This is the phone's build.Bundle error
mobile-android · pausedReal native compile, JDK 17.Never — advisory
e2e-web · pausedPlaywright over the build: sign in, open a trip, start one. Own seeded database on port 3100.A failed flow (report kept 7 days)
migrationsRuns db:generate. No database.Schema change with no migration
parityCompares scripts/parity/parity.json to the router and the app.A procedure with no declared phone status
wireframes · pausedChecks plain HTML wireframes.External asset or doc wrapper
secretsgitleaks over full history.A secret, even an old one
auditpnpm audit --audit-level=high.High or critical advisory
sync developOn push to main, merges it back into develop.Merge conflict

Rules

  • A new push to a branch cancels its old run. Sync develop is the exception.
  • contents: read everywhere. Sync develop needs write.
  • Node 22, pnpm, --frozen-lockfile in every job.
  • scripts/verify.sh mirrors the check jobs. Change a check job, change verify in the same commit.
  • Not in CI: Maestro phone flows and store builds. Run them by hand.
