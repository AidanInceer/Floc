Editing these docs

HTML is the source. There is nothing to regenerate from — edit the page. To add one, copy the shell from any existing page (data-root is the path back up to docs/, data-page is the page id) and add a matching entry to TREE in assets/nav.js. A page missing from TREE is unreachable.
