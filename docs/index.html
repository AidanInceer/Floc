Editing these docs

HTML is the source now — there are no Markdown originals to regenerate from. Edit the page directly. To add a page, copy the shell from any existing one (data-root is the relative path back up to docs/, data-page is the page id) and add a matching entry to the TREE array in assets/nav.js, which is the one place the sidebar is defined.
