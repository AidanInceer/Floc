Floc — backlog

The committed cut. Every item on this page is an open GitHub issue in AidanInceer/Floc, linked from its row. Items keep the number they carried on the previous version of this page, so an older reference still resolves.

Priority key: 🔥 top · 🟠 medium · 🔵 normal · ⚪ low / future.
Readiness key: ✅ ready to build · 🎯 needs a grilling session first · ❓ verify against the code before ticketing.

Every item here means grilling (where marked) → implementation → tests. None of them are UI-only.

C3 Shared live location
#168		 Reopened — judged potentially useful after all. v1 rejected it as a privacy liability with no planning value, so the grilling has to answer that objection head-on before anything is built. 🔵 🎯
C1 AI itinerary generation
#178		 In for the long term, as a paid feature — but the groundwork has to exist first. v1's objection stands and must be designed around: generated plans have no social legitimacy, so this augments the group's decision rather than replacing it. ⚪ low 🎯
