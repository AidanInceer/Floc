# Competitor: Wanderlust

**URL:** https://www.wanderlustapp.io/  
**Positioning:** "Plan it. Live it. Share it." — AI trip planner grounded in real city data, with offline live-travel mode and a social discovery layer.

---

## Features

### Planning
- AI itinerary builder grounded in real city, cost, and safety data (not generic LLM output)
- Day optimiser — reroutes a single day's stops for least transit time, previews minutes saved before committing
- Drag-to-reorder itinerary pinned to a map
- 1,300+ cities, 190+ countries of city data

### Discovery & inspiration
- Curated editor guides per city (neighbourhoods, food lists, starter itinerary)
- Browse by category: safest cities, cheapest, best for digital nomads, etc.
- `/explore` feed — shared journeys and bookable group trips interleaved in one feed
- Clone any shared trip into your own editable version ("plan my own version")
- Browser extension — clips articles, Instagram posts, and hotel pages into the right trip

### Live travel (Trip Mode)
- Offline-first today-view on mobile
- Current stop highlighted; next stop with countdown timer
- One-tap native directions (Apple Maps / Google Maps)
- Timezone-aware; loads from cached trip with no signal required

### Social & sharing
- Publish trips publicly, discoverable in `/explore`
- Bucketlist — save cities, restaurants, and gems before you have a trip; surfaced when starting a nearby trip
- Travel Passport — living world map of visited countries, auto-filled from forwarded booking confirmation emails
- Passport stats: countries visited, cities, miles flown, days on the road
- Single-link shareable passport (private by default)

### Collaboration
- Invite co-planners
- Vote on activities
- Running cost split

## Gaps vs Waypoint

| Gap | Priority notes |
|---|---|
| **Trip Mode / offline live travel** | Biggest gap — real-time "what's next" view while actually on the ground |
| **Route / day optimiser** | Waypoint has a route page but no "optimise this day" with preview |
| **Travel Passport & stats** | Visited-country map, cumulative travel stats, auto-import from email |
| **Bucketlist** | Save places before a trip exists, surface them when relevant |
| **Clone / fork trips** | Public trip → "plan my own version" flow |
| **Browser extension** | Clip web content directly into a trip |
| **City data layer** | Wanderlust bakes in cost, safety, and neighbourhood intel; Waypoint has none |
| **Publisher tier** | Monetised guide and group-trip publishing for creators |
| **Activity voting** | Collaboration exists in Waypoint but no async voting mechanic |

**Most strategically important for a group-travel planner:** day optimisation and activity voting — the two pain points groups hit most. Trip Mode and the Travel Passport are stronger differentiators for solo/repeat travellers and are lower priority for the current pre-MVP scope.
