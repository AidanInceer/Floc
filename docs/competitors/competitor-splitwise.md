# Competitor: Splitwise

**URL:** https://www.splitwise.com/  
**Positioning:** "Less stress when sharing expenses" — a dedicated expense-splitting tool for groups, trips, housemates, and couples. Not a travel planner; purely a money-management layer.

---

## Features

### Core (free)
- **Groups** — create a group per trip, household, or any shared context
- **Add expenses** — log any expense, assign who paid, split among any subset of the group
- **Split modes** — equal split, unequal amounts, by percentage, by shares
- **Balance tracking** — running per-person balance; shows exactly who owes whom
- **Simplify debts** — collapses a web of IOUs into the minimum number of transfers
- **Settle up** — record a cash payment or trigger an online payment to zero a balance
- **Recurring expenses** — set up a repeating charge (e.g. monthly rent)
- **Offline mode** — works without a connection, syncs when back online
- **Cloud sync** — consistent state across all devices
- **Spending totals** — aggregate view of what a group has spent
- **Categorise expenses** — tag by food, transport, accommodation, etc.
- **100+ currencies** — multi-currency groups
- **7+ languages**
- **Payment integrations** — link PayPal, Venmo (US), etc. for in-app settlement
- **Unlimited expenses**
- **Transaction import**

### Pro (paid)
- **Receipt scanning** — photograph a receipt and auto-extract line items
- **Itemisation** — split individual line items from one bill differently
- **Charts and graphs** — visual spending breakdown
- **Currency conversion** — auto-convert expenses to a base currency
- **Expense search**
- **Save default splits** — remember how a group usually splits
- **Ad-free**
- **Early access to new features**

### Adjacent products (mentioned in footer)
- **Splitwise Pay** — in-app payment product
- **Splitwise Card** — co-branded payment card

## Gaps vs Waypoint

| Gap | Notes |
|---|---|
| **No trip planning** | Splitwise is purely financial — no itinerary, map, or activity planning |
| **No travel-specific features** | No flights, hotels, routes, or destination discovery |
| **No collaboration beyond money** | Groups exist only for expense purposes; no shared itinerary or decision-making |
| **No AI** | Manual expense entry only (Pro adds receipt scanning) |
| **No social/discovery** | Entirely private; no community or inspiration layer |

**Strategic note:** Splitwise is the de-facto standard for group expense splitting — it has strong brand recognition and trust for this single job. Waypoint's money module competes here directly. To win, Waypoint's advantage is that the expense context (who went where, what was booked) already lives in the trip — no need to re-enter it. The risk is that groups already have Splitwise habits and won't switch for a less-featured money tool embedded in a planner.
